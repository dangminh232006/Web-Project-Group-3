## What the AI did **not** do

- It did not invent any member name, student ID, quote, translation, fun fact or
  contribution record. Every one of those is a visible placeholder.
- It did not create a group photograph or substitute an illustration for one.
- It did not create a GitHub repository, deploy anything, create a Jira project,
  or submit anything to Canvas.
- It did not fabricate URLs. Destinations that were not supplied are rendered as
  visible pending markers.
- It did not invent testimonials, hiring statistics, awards, partnerships or
  market salary research. The salary bands are stated in the code as illustrative
  scenario figures.
- It did not claim an accessibility score, and no automated accessibility scoring
  tool was run.

## Human review still required

**This matters for academic integrity.** At the time of writing, the code had been
generated and tested by an AI assistant, but **not yet reviewed line by line by
the students who will submit it.**

Before submission, each member must:

1. Read the page they own, in full, and be able to explain every element.
2. Change what they disagree with. Work you have not questioned is work you
   cannot defend in the interview.
3. Fill in their own placeholders.

at the top of each HTML page:

```html

  Generative AI acknowledgement (unit requirement):
  Parts of this page were drafted with assistance from Claude (Anthropic, Opus 5,
  September 2026). All markup was reviewed, edited and tested by the team before
  submission. Full statement: docs/ai-use.md

```

**If a member has not actually reviewed and edited their page, that comment is not
yet true for that page.** Either do the review, or change the wording to match
what really happened. The unit page is explicit: *"Failure to credit GenAI or
other sources constitutes plagiarism."*
