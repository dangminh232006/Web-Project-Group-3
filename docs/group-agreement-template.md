## 5. Standards we agree to follow

- Only HTML5 and CSS3. No JavaScript, no Bootstrap, no external libraries.
- Comment our code. The unit states that marks are lost for uncommented code.
- Acknowledge any generative AI use in code comments, with tool name, version and
  how it was used, per the unit requirement.
- Acknowledge any external source in a comment next to the code it influenced.
- Never commit another member's content or type their initials.

## 6. If something goes wrong

| Situation | What we will do |
|---|---|
| A member misses an agreed deadline | Raise it at the next stand-up, agree a new date, record it in Jira |
| A member is unreachable for more than one week | Contact the tutor rather than silently absorbing the work |
| We disagree on a technical decision | Record both options in `decisions.md`, pick one, and note why |
| Someone falls behind because of illness or workload | Redistribute openly and record it, so the peer evaluation reflects reality |
