Apply for a role

One form covers one vacancy. Take the five character reference number from the vacancy you want and type it into the first field.

This is a student prototype, not a real recruitment system. It was built for COS10026 coursework. Submitting the form sends the fields to a Swinburne test script that echoes them back to you; nothing is stored by this site, and no application is received by anyone. Please enter made-up test data only. Do not enter a real date of birth, a real address, or any other genuine personal information.

Fields marked * (required) must be completed. Only Other skills is optional.
