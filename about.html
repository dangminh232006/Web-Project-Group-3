Selected project brief

For Assessment 2: Applied Web Project - Part 1, Group 3 selected Apple as the company for a static recruitment website. The site presents the Apple Online Store web team and helps prospective applicants explore the available roles and complete a job application form.

  • Company and team: Apple, Apple Online Store web team in Sydney.
  • Advertised roles: Front-End Web Developer (AFE26) and Accessibility and UX Designer (AUX26).
  • Website pages: Home, Jobs, Apply and About.
  • Technology and delivery: HTML5 and CSS3, with responsive layouts, HTML5 form validation and hosting on GitHub Pages. Part 1 does not use JavaScript or a database.

This is an educational project. The vacancies and salaries are fictional, the site is not affiliated with Apple, and the application form sends made-up test data to Swinburne's form test server.

Why we chose Apple

Apple is known for clean design, attention to detail and a strong focus on accessibility and privacy. Building a careers site in that style pushed us to keep the layout simple, use plenty of white space, write in plain language and check every page with the W3C validators and an accessibility checker.
