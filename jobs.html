Front-End Web Developer, Apple Online Store

Reference number: AFE26

Build and improve the pages customers use to explore, compare and buy Apple products online. You will turn designs into fast, standards-based and accessible HTML and CSS that works on every screen size, from iPhone to Pro Display XDR.

Job details

Salary
AUD $115,000 to $135,000 per year, plus superannuation
Reports to
Engineering Manager, Online Store Web Team
Location
Sydney, NSW (hybrid)
Work type
Full time, permanent
Closing date
30 November 2026

Key responsibilities

  • Build product and checkout pages in semantic HTML5 and CSS3 from design files.
  • Make every layout responsive and test it on phones, tablets and desktop browsers.
  • Check pages against accessibility guidelines and fix issues found with tools such as WAVE.
  • Keep code valid using the W3C HTML and CSS validators.
  • Review other developers' code and share what you learn with the team.

Requirements

Essential (in order of importance)

  1. Strong skills in HTML5 and CSS3, including Flexbox, Grid and media queries.
  2. Experience building accessible websites, including forms and tables.
  3. Experience with Git and GitHub in a team.
  4. Clear written and spoken communication in English.

Preferable

  • A degree or diploma in IT, computer science or a related field.
  • Experience with e-commerce or retail websites.
  • Experience working in an Agile team using Jira.

Apply for this role Use reference number AFE26.

Accessibility and UX Designer, Apple Online Store

Reference number: AUX26

Help make shopping with Apple simple for every customer, including people who use screen readers, keyboards, voice control or larger text. You will design page layouts, test them with real users and work with developers to turn the results into improvements.

Job details

Salary
AUD $105,000 to $125,000 per year, plus superannuation
Reports to
Design Lead, Online Store Experience
Location
Sydney, NSW (hybrid)
Work type
Full time, permanent
Closing date
30 November 2026

Key responsibilities

  • Design page layouts, forms and navigation for the online store.
  • Run usability tests with customers, including people with disability.
  • Check colour contrast, heading order, alternative text and form labels in every design.
  • Write clear, plain-language content for product and help pages.
  • Make sure designs avoid dark patterns such as hidden costs or trick questions.

Requirements

Essential (in order of importance)

  1. Examples of user-centred and accessible design work, from a portfolio or from study, work or community projects.
  2. Good knowledge of web accessibility guidelines (WCAG).
  3. Experience planning and running usability tests.
  4. Basic understanding of HTML and CSS.

Preferable

  • Experience testing with screen readers such as VoiceOver.
  • Experience designing for e-commerce or retail.
  • A qualification in design, human-computer interaction or a related field.

Apply for this role Use reference number AUX26.
